# Branding LuaNails

## Paleta de Colores

| Color | Hexadecimal | Uso Principal |
| :--- | :--- | :--- |
| **Dorado (Gold)** | `#837751` | Detalles de lujo, botones CTA, acentos y hover states. |
| **Oscuro (Dark)** | `#1A1A1A` | Texto principal, fondos oscuros, menús. |
| **Blanco (White)** | `#FFFFFF` | Fondos limpios, texto sobre fondos oscuros. |

## Efectos Especiales

- **Brillo (Glow)**: Se aplica un efecto de sombra/resplandor a los botones dorados (clase `.btn-glow`) para darles un aspecto vibrante.
